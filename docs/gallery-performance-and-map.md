# 图库加载、存储与地图视图

图库接口由 SQLite 执行筛选、排序和分页。`GET /photowall/api/photos` 默认返回 120 张，`limit` 最大为 500；响应的 `pagination` 包含总数和后续页状态。相同日期使用照片 ID 稳定排序。

前端滚动时追加页面。网格、瀑布流和时间线只挂载视口及其上下 800px 范围的卡片。筛选切换会取消旧请求；加载失败显示重试入口。全选使用 `/photos/ids` 获取全部匹配 ID，不受已加载页数限制。幻灯片仍在进入放映时按页获取完整的照片元数据快照，保持随机播放和方向筛选行为；超大图库的放映初始化仍会占用与照片数量相关的时间和内存。

服务端不再常驻一份完整照片对象集合。扫描根据文件修改时间、大小、元数据版本及缩略图存在性复用目录记录；变化记录通过事务批量写入。缩略图、预览图和展示图生成请求去重，并先写临时文件，再移动到最终缓存路径，避免读取未完成文件。图片 URL 携带源文件版本，防止浏览器长期缓存旧图。

自动清理依据 SQLite 中的有效缩略图引用删除过期缩略图及配套模糊占位图，保留当前图库所需文件。`maxCacheSize` 不再用于强制淘汰有效缩略图，避免大图库启动后反复生成。预览和展示图片仍采用现有磁盘缓存策略。

地图入口位于“布局”工具组。地图沿用分类、模糊搜索和语义搜索结果；服务端按地图范围、缩放级别聚合坐标，仅返回代表照片、数量和范围。点击聚合封面查看该地点的分页相册，也可放大查看；点击照片打开灯箱。关闭灯箱保留地图位置，切换视图后也恢复位置。地图代码和 Leaflet 在首次进入地图时加载。

地图使用原始 EXIF GPS（WGS84），支持合法的零经纬度。无定位照片仅统计数量，不生成推测坐标。支持 OpenStreetMap 普通底图及 Esri 卫星底图，底图需要联网；加载失败显示重试提示。

数据库升级保留原有记录，新增纬度、经度、文件大小和元数据版本。升级后的首次扫描会补提取历史照片 GPS，之后未变化照片直接复用。重启服务端即可执行迁移和扫描。

验证命令：

```powershell
npm run gallery:test
npx tsc --noEmit
npm run build
npm run auth:test
npm run upload:test
```

`gallery:test` 使用临时数据库和合成图片，覆盖旧库迁移、两万张记录分页及查询计划、过滤、GPS 聚合、缓存失效、增量扫描、过期缓存清理、虚拟布局可见范围，以及实际 HTTP 请求。
